# 题目:查找在职员工自入职以来的薪水涨幅情况

编号:**SQL220**

<span style = "color:red">较难</span>  通过率：21.26% 时间限制：1秒 空间限制：32M

## 描述

有一个员工表employees简况如下:

| emp_no | birth_date | first_name | last_name | gender | hire_date  |
| ------ | ---------- | ---------- | --------- | ------ | ---------- |
| 10001  | 1953-09-02 | Georgi     | Facello   | M      | 2001-06-22 |
| 10002  | 1964-06-02 | Bezalel    | Simmel    | F      | 1999-08-03 |

有一个薪水表salaries简况如下:

| emp_no | salary | from_date  | to_date    |
| ------ | ------ | ---------- | ---------- |
| 10001  | 85097  | 2001-06-22 | 2002-06-22 |
| 10001  | 88958  | 2002-06-22 | 9999-01-01 |
| 10002  | 72527  | 1999-08-03 | 2000-08-02 |
| 10002  | 72527  | 2000-08-02 | 2001-08-02 |

请你查找在职员工自入职以来的薪水涨幅情况(注意这里强调的是在职员工)，给出在职员工编号emp_no以及其对应的薪水涨幅growth，并按照growth进行升序，以上例子输出为

（注: to_date为薪资调整某个结束日期，或者为离职日期，to_date='9999-01-01'时，表示依然在职，无后续调整记录）

| emp_no | growth |
| ------ | ------ |
| 10001  | 3861   |



**<span style="color: #87CEFA">解题思路:</span>**

<span style="color:teal">首先我们先找出最初的工资即 `from_date`=`hire_date`的这部分为初始工资,然后再找出`ti_date`=`9999-01-01`对应的salary为现在的工资,`growth`的增长则是`现在工资`-`初始工资`</span>



```mysql
SELECT new.emp_no,new.salary - old.salary AS growth
FROM(
    SELECT e.emp_no,s.salary 
FROM employees e JOIN salaries s
ON  e.emp_no = s.emp_no AND e.hire_date = s.from_date
)old
JOIN (
SELECT e.emp_no,s.salary
FROM employees e JOIN salaries s
ON e.emp_no = s.emp_no
where s.to_date = '9999-01-01')new
ON old.emp_no=new.emp_no
ORDER BY growth asc;

```



<span style="color:cyan">小细节</span>

有两种写法:

```mysql
---------------在ON中写-------------------
ON  e.emp_no = s.emp_no AND e.hire_date = s.from_date
---------------在WHERE中写-----------------
ON  e.emp_no = s.emp_no
WHERE e.hire_date = s.from_date

```

虽然两者都对，但**第一段（使用 `ON`）**通常被认为更符合 SQL 规范和现代编写习惯。

**逻辑紧凑**： 在 `old` 子查询中，我们要找的是“入职时的那一笔薪水记录”。入职的定义就是 `hire_date = from_date`。将这个逻辑写在 `ON` 中，使得 `JOIN` 的意图非常明确：**“我要找的是那个特定时间点的关联记录”**。

**避免笛卡尔积风险**： 虽然在这个特定的 `JOIN` 里没问题，但在复杂的 `LEFT JOIN` 环境下，`ON` 和 `WHERE` 的结果会完全不同。养成在 `ON` 中写完所有关联条件的习惯，可以减少逻辑错误。
